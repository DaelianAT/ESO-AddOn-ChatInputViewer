This AddOn was written especially for role-players.

When role-playing in ESO you encounter the problem that you can't see the complete text you have entered in the chat input field.

This AddOn displays the complete text in a separate field, placed directly below the chat window.

The text is shown in the same color as the text in the Input field. When the input reaches 80% of the maximum possible number of characters, the text colour changes to yellow, at 90% to orange and at 100% to red.

The window can also be displayed in a minimised view, showing only the number of characters already used and the number of characters allowed. Here, too, the colours yellow, orange and red indicate at a glance how much space you still have for your post.

The AddOn provides three Chat commands (slash commands):
/civshow   shows the viewer window in full size.
/civhide   makes the viewer window invisible
/civmini   shows the Viewer window in minimized mode.

You can bind a keyboard key to the AddOn to tuggle the three visibility modes.

In the Settings the font size, window width and the number of displayed lines can be set.


== Dependencies ==

LibAddonMenu-2.0 (Version >= 40)


== Supported Languages ==

EN, DE, FR, RU


== Please note ==

The chat window normally extends to the bottom of the screen. If the window is not automatically moved upwards when the AddOn is made visible, the bottom edge of the chat window must be moved upwards manually.

This is a known issue I have not yet been able to fully resolve.
